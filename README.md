## 🚀 Featured Projects

### [Career Scout AI](https://github.com/IgorVinson/career-scout-ai)
AI-powered job matching tool — analyzes your CV and finds relevant opportunities using Google Gemini.
- **Tech:** React, TypeScript, Vite, Google Gemini AI, Firebase
- **Features:** CV parsing, smart job matching, drag-and-drop pipeline

### [Voice to Invoice](https://github.com/IgorVinson/voice-to-invoice-gemini)
Voice-powered invoicing app for field workers — speak job details, AI generates the invoice.
- **Tech:** React, TypeScript, Vite, Google Gemini AI
- **Features:** Speech recognition, AI data extraction, PDF export

### [FN Assistant](https://github.com/IgorVinson/fn-asistant)
Production automation tool for FieldNation & WorkMarket job platforms — real-time job monitoring, auto-application, and Telegram notifications.
- **Tech:** Node.js, Express, Puppeteer, Google Calendar API, Telegram Bot
- **Features:** Dual platform automation, smart filtering, calendar sync

### [Easy Expenses](https://github.com/IgorVinson/easy-expences)
React Native mobile expense tracker with Firebase auth and real-time sync.
- **Tech:** React Native (Expo), TypeScript, Firebase
- **Features:** Cross-platform, offline support, budget tracking

### [MetricFlow](https://github.com/IgorVinson/scoreboard)
Analytics dashboard SaaS for tracking objectives, metrics, and reports with Stripe subscriptions.
- **Tech:** React, TypeScript, Supabase, Stripe, shadcn/ui, TipTap
- **Features:** OKR tracking, rich text reports, subscription management

### [Family Win Tracker](https://github.com/IgorVinson/family-win-tracker)
Family gamification app — track kids' goals, achievements, and rewards with a scoring system.
- **Tech:** React, TypeScript, Supabase, Tailwind CSS, shadcn/ui
- **Features:** Point system, reward store, invite system

### [EasyBudget](https://github.com/IgorVinson/easyBudget)
Full-stack budget management web app with multi-language support.
- **Tech:** Next.js 13, TypeScript, Prisma, MongoDB, NextAuth
- **Features:** Transaction tracking, data visualization, i18n

### [Job Application Assistant](https://github.com/IgorVinson/fill-form-extention)
Chrome extension that auto-fills job application forms using AI-powered smart matching.
- **Tech:** JavaScript, Chrome Extension API, OpenAI/DeepSeek
- **Features:** Auto-form detection, cover letter generation, CV parsing
